# BEEM138 Problem Set 4 – Neoclassical Growth Model (Shooting Algorithm)

Solves the saddle path of the neoclassical growth model in Julia.

## Run
```bash
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. src/main.jl
```
Figures are saved in `figures/`.

## Files
- `src/main.jl` – full solution (parts a–d)
- `Project.toml` – dependencies (Plots.jl)
- `figures/` – output plots
